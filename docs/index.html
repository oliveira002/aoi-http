API calls, without the noise.

Aoi imports your OpenAPI and Postman files and gives you a fast, quiet place to send requests, switch environments and read responses.

01

Bodies that know the spec

Aoi reads each endpoint's schema from your spec and helps as you type, so a request body matches the API before you send it.

  • Fields with their types and descriptions
  • Allowed values for enums, at any depth
  • Required fields flagged, examples in one click
02

One base URL per environment

An environment is a base URL plus the few values it needs. Pick Local, Staging or Production next to the request and every request follows, with anything still missing highlighted.

03

Jump anywhere with ⌘K

Press ⌘K or click the search bar, then type a few letters to open any request, switch environment, or copy the current request as cURL. Tabs keep your work side by side.

04

A second look before production

Mark an environment as production and Aoi shows the full URL and asks before anything that changes data, so a write only reaches production when you mean it to. Settings let you ask for every request, or never.

Get started

Get the code and build it It installs itself in Applications.
Terminal 
git clone https://github.com/oliveira002/aoi-http.gitcd aoi-http && ./bundle.sh
Import a spec Drop an OpenAPI or Postman file on the sidebar, or press ⌘O.
Pick an environment Give it a base URL, open a request and click Send.

Needs macOS 14 or later and Swift 5.10.
